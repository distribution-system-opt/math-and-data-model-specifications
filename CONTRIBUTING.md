# Contributing

Corrections, clarifications, examples, and modelling proposals are welcome.
The [Task Force contribution guide](docs/src/contributing.md) defines the
existing governance, review tiers, modelling principles, licensing, and release
process. The [maintainer list](MAINTAINERS.md) identifies the current maintainers.

Issue forms and the PR template help record related work, evidence, dependencies,
and contributor credits. They do not introduce a separate approval process.
